# Kunbiola Resources Ltd

> **Nigeria's Finest Commodities, Delivered Globally.**

Kunbiola Resources Ltd is a modern, responsive web application for an international agro-allied and solid minerals export company based in Lagos, Nigeria. The platform connects local producers with international buyers, showcasing agricultural commodities (cashew nuts, cocoa, sesame seeds, ginger, hibiscus, shea butter) and solid minerals (copper, iron ore, magnesium ore, lead ore, gemstones).

---

## 🌟 Key Features

- **Dynamic Hero Section**: Responsive full-viewport hero banner with fluid typography and scalable visual assets.
- **Product Catalogue**: Full interactive 15-product showcase (with responsive grid layout and balanced item distribution).
- **Interactive "Request a Quote" Modal**: Global overlay with direct access to WhatsApp, Phone, Email, and physical headquarters channels.
- **About Us Page**: Corporate background, mission statement, values, and trade expertise.
- **Contact Us with Google Maps**: Interactive Google Maps iframe embed showing company headquarters, opening hours, and direct communication channels.
- **Responsive Mobile Navigation**: Smooth right-sliding navigation drawer with integrated quick contact shortcuts.
- **Tailored Design System**: Custom typography (Righteous & Inter) paired with rich brand colors (Forest Green, Gold, Mint, Offwhite).

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BIGFOOT-DEV/Kunbiola-Resources.git
   cd Kunbiola-Resources
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173` to view the application.

---

## 📜 Available Scripts

- `npm run dev` — Starts the local development server with Hot Module Replacement (HMR).
- `npm run build` — Compiles and bundles the application for production deployment.
- `npm run preview` — Locally previews the production build.
- `npm run lint` — Runs Oxlint for fast code analysis.
